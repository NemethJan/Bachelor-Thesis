# Bachelor-Thesis

This repository contains the code and documentation for the ongoing work of the Bachelor's thesis. 
The notebooks folder currently contains the Data Preparation Notebook and the EDA of the underlying data, and will soon feature a Data Preprocessing & Machine Learning Notebook. 
The 'Writing Sample' folder contains the first draft of my Bachelor's thesis in Word format. 
Due to storage constraints, the raw datasets are stored on the University OneDrive, to which my supervisor has access. 
The datasets were obtained from Wharton Data Research Services and cannot be shared further due to university regulations. 
However, direct links to the folder containing the literature can be shared on request.
